# 知识库维护工具（.kb 目录，不属于 Obsidian 笔记内容）

## 目录说明
- `seeds.json` / `seeds/KB-xxx.md`：每篇 PDF 的元数据与正文节选（摘要、引言、结论），供撰写笔记时使用。
- `text/KB-xxx.txt`：pdftotext 抽出的正文（前 8 页 + 后 9 页），双栏可能交错。
- `dedupe.json`：md5 去重结果（201 个 PDF → 197 篇）。
- `qa.py`：质量检查（板块完整性、frontmatter、断链、文件名、主题归属、重复标题）。
- `build_index.py`：重建 `01_索引主页/文献总览.md`、`名词索引.md`，并回填术语的"关联文献"和笔记的"🔗 关联"。
- `make_terms.py`：术语卡片生成（术语表冻结在脚本里，新增术语改 `T` 列表后重跑）。
- `PROMPT.md`：撰写单篇笔记的完整规范（链接白名单、板块结构等）。
- `qa_report.md`：最近一次检查报告。

## 新增一篇论文的标准流程
1. 把 PDF 放进 `../`（即 `ROBOT/` 目录）。
2. 运行 `python3 .kb/build_seeds.py`（重新生成全部种子；会自动去重，重复文件不重复建笔记）。
3. 让模型按 `.kb/PROMPT.md` 为新增的 `KB-xxx` 写笔记到 `02_文献库/<主题>/`。
4. 运行 `python3 .kb/build_index.py && python3 .kb/qa.py`，按报告修断链与缺板块。

## 常用校验
- `python3 .kb/qa.py`：列出错误（必修）与警告（建议修）。
- `python3 .kb/qa.py --strict`：有错误时返回非零退出码，适合定时巡检。

## 约定
- 笔记文件名 = 论文标题，非法字符 `: / \ ? * " < > |` 替换为空格。
- `pdf:` 字段写相对笔记的 PDF 路径（库外文件用 `../../../`）。
- 术语链接只允许白名单（见 `PROMPT.md`）；清单外的专业名词写成 `【待建名词：xxx】`。
- 索引文件由脚本生成，不要手改。
