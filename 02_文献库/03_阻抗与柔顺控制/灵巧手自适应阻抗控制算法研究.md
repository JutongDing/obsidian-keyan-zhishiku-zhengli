# 灵巧手自适应阻抗控制算法研究

## 📌 年份
2023

## 🔑 论文识别码
KB-191（本地编号，原文无 DOI/arXiv）

## 👥 作者与所属院校
- 作者：时文（指导教师：赵兴强）
- 机构：南京信息工程大学 自动化学院（电子信息，硕士专业学位）

## 📖 研究背景
- [[灵巧手]]用于替代人手在危险区域作业，要求抓取稳定且能顺应外力。
- 固定阻抗参数的[[阻抗控制]]在环境刚度未知或突变时，接触力超调大、稳态误差高。
- 抓取位置与抓取力若未事先规划，力封闭条件难以保证，柔顺控制缺少可靠初值。

## ❓ 需要解决的问题
- 如何在[[摩擦锥]]与[[力封闭]]约束下求出稳定抓取的初始位置，并用稳定性指标寻优？
- 抓取力能否用梯度流法在接触点处优化到最优值？
- 位置型阻抗控制中，刚度、阻尼、惯性参数如何影响接触力响应？
- 模型参考自适应模块能否降低接触力超调与稳态误差，并在环境位置突变时保持跟踪？

## 📥📤 输入与输出
- 输入：手指关节角、指尖接触力、期望接触力、物体几何与接触点位置、环境位置变化。
- 输出：最优抓取位置、各接触点[[抓取力优化]]结果、关节位置指令、接触力跟踪曲线。

## ✅ 论文最终达到的效果
- 基于 D-H 法建立食指与拇指正逆运动学，导出[[雅可比矩阵]]，静力学给出指尖力与关节力矩关系。
- 以最大内切圆法则优化抓取位置，梯度流法完成抓取力优化。
- 位置内环对比 PD 与滑模控制后选用滑模控制，再叠加模型参考自适应，构成自适应阻抗控制。
- 6 N 阶跃实验：传统阻抗峰值 8.12 N、超调 35%；自适应阻抗峰值 6.45 N、超调 7.5%；力波动幅度由 2.9 N 降到 1.1 N。
- 接触力相对误差均值由 19.4% 降到 6.43%；环境位置突变时接触力跳变由 0.9 N 降到 0.48 N，2 N 与 10 N 工况结论一致。
